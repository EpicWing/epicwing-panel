# Code of Conduct

We want EpicWing to be a friendly place for everyone who uses it or contributes to it.

- Be respectful. No harassment, insults or discrimination.
- Assume good intent. Keep feedback about the work, not the person.
- No spam or unrelated advertising in issues, discussions or pull requests.
- Do not publish other people's private information.

Maintainers may edit or remove comments, close issues and block users who break these rules.
To report a problem, write to support@epicwing.de.
