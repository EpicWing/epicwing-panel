# EpicWing

Ein leichtgewichtiges, selbst hostbares Panel für Game-Server, Webanwendungen
und andere Serverdienste.

> **Status: frühe Entwicklung.** Es funktioniert noch nichts davon produktiv.
> Nicht installieren, wenn du ein stabiles Panel suchst.

## Geplante Komponenten

- `backend/`: API (Python, FastAPI, PostgreSQL)
- `frontend/`: Weboberfläche (Vue 3, TypeScript) – noch nicht begonnen
- `agent/`: Node-Agent (Go) – noch nicht begonnen
